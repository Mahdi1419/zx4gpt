# RelaySMS

اپلیکیشن بومی اندروید برای کنترل تجهیزات پیامکی مانند کنترلر ZX4، شیر موتوری، پمپ، در و رله‌ها.

## قابلیت‌های فعلی
- ارسال فرمان‌های SMS قابل ویرایش برای باز، بسته و توقف
- تنظیم شماره سیم‌کارت کنترلر
- تایمر مدت‌دار: ارسال فرمان شروع و سپس ارسال فرمان پایان
- لغو تایمر فعال
- نمایش زمان باقی‌مانده تقریبی
- رابط فارسی و راست‌چین
- ساخت APK با GitHub Actions

## فرمان‌های پیش‌فرض ZX4
- باز: `OUT#1000`
- بسته: `OUT#0100`
- توقف: `OUT#0000`

این نگاشت فقط پیش‌فرض است و از تنظیمات برنامه قابل تغییر است. قبل از استفاده واقعی، جهت حرکت خروجی‌ها را با موتور و سیم‌کشی ایمن تأیید کنید.

## بیلد محلی
نیازمندی‌ها: JDK 17، Android SDK و Gradle 8.9.

```bash
gradle assembleDebug
```

APK خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## بیلد با GitHub Actions
1. محتوای ZIP را در یک repository جدید GitHub قرار دهید.
2. به تب Actions بروید و workflow با نام **Build Android APK** را اجرا کنید یا یک commit push کنید.
3. فایل APK را از بخش Artifacts همان اجرای workflow دانلود کنید.

Workflow از JDK 17 و Gradle 8.9 استفاده می‌کند و به Gradle Wrapper نیاز ندارد.

## مجوزها و محدودیت‌های اندروید
- برای ارسال پیامک، مجوز SMS باید داخل برنامه تأیید شود.
- بعضی گوشی‌های دو سیم‌کارته ممکن است سیم‌کارت پیش‌فرض پیامک را انتخاب کنند.
- زمان‌بندی دقیق ممکن است به تأیید مجوز Alarms & reminders نیاز داشته باشد؛ در صورت نبود آن، برنامه از آلارم غیردقیق به‌عنوان fallback استفاده می‌کند.
- بهینه‌سازی باتری سازنده گوشی ممکن است اجرای پس‌زمینه را محدود کند.
- برنامه می‌تواند ارسال فرمان را درخواست کند، اما بدون پاسخ معتبر از کنترلر نمی‌تواند وضعیت واقعی شیر یا موتور را تأیید کند.
- تایمر نرم‌افزاری جایگزین حفاظت سخت‌افزاری، محدودکننده انتهای مسیر یا نظارت در کاربردهای پرخطر نیست.

## معماری
- Kotlin + Jetpack Compose
- AlarmManager برای تایمر
- SharedPreferences برای تنظیمات و تایمر فعال
- BroadcastReceiver برای اجرای فرمان پایان و بازیابی تایمر بعد از reboot
